Backup data about pollutants from Open Meteo. Data is not raw, it is from CAMS reanalysis. 

CAMS:
It assimilates real ground-station observations (including EEA stations) into the model
It's a model output on a regular grid (~10km resolution) (not a raw sensor reading)
It smooths and interpolates, local peaks get averaged out

Pre computed EAQI, etc. We can use this if the raw data is not good enough.
